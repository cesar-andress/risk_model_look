## Target

**Empirical Software Engineering (EMSE)**

## Why EMSE

Final diagnostics support a methodological lesson: line-level explanation conclusions for this JIT decoder classifier **depend on the validity criterion**.

- Localization: methods beat canonical order; none beat payload-token line length; Attention’s interval vs random excludes 0 while Wilcoxon-Pratt does not reject.
- MEAN token aggregation reduces Attention Recall@20 and **does not** reverse the length-baseline lesson (methods still fail to outperform length).
- Perturbation: Attention and Grad×Input both exceed a token-matched random ranking; their pairwise AOPC gap is smaller.
- Rankings: Attention is more seed-stable than Grad×Input/occlusion even after length residualization; within-seed agreement with occlusion is weak.
- Official numerical-path gate remains FAIL; aggregate D is highly correlated across bf16/fp32 scoring-only paths (POST-HOC).

That is an evaluation-methodology contribution with mixed/negative results, which matches EMSE’s empirical-methods remit (fit 5/5 in the independent review, retained after MEAN/length analyses).

## Why not IST as primary

IST would be more natural if MEAN aggregation had erased the structural-baseline lesson and left only a bounded method bake-off. Outcome A/B of the lock: **A** (methods still fail to clearly outperform length). EMSE remains primary.

## Main contribution

A criterion-separated evaluation showing that plausible localization, structural baselines, perturbation impact, polarity, seed stability, and numerical-path checks can disagree on the same model and dataset.

## Main limitation

Single decoder family, single Java JIT resource, NF4 quantization, no executable encoder baseline, RQ2 PAYLOAD_BLANK only, IG largely non-estimable.

## Fallback condition

If reviewers treat the work as a single-model bake-off without accepting the criterion-dependence thesis, reposition for IST **without new experiments**.
