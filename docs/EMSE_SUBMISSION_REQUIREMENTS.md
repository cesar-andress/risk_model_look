## Article type / review

- Research article; single-blind peer review (authors identified; reviewers anonymous).
- Not double-blind. Title page may include names, affiliations, ORCID, corresponding email.

## Formatting (from Springer instructions, retrieved 2026-10-06)

- Abstract: 150–250 words; no undefined abbreviations or unspecified references.
- Structured abstracts permitted (Context / Objective / Method / Results / Conclusions), not required.
- Keywords: 4–6.
- Headings: decimal system, at most three levels (apply at production/SVJour3 upload; current draft uses named LaTeX sections).
- Word or LaTeX; mathematical content may use Springer Nature LaTeX (SVJour3). FAQ: use the template linked from the Springer page, not an outdated Overleaf copy as authority.
- Author-year citations; reference list alphabetized by first author; include DOI URL when available.
- Footnotes, not endnotes.
- Statements and Declarations required (competing interests, etc.) or the submission is returned incomplete.
- LLM/AI: models are not authors; document LLM use in Methods except “AI assisted copy editing” as defined by Springer.
- No submission/publication fee; optional Open Access APC after acceptance.
- Editable source files required at every submission; LaTeX: avoid subfolders for figures/bib if following Springer’s compile path.

## Length

No numeric page/word cap stated on the retrieved Springer guidelines page beyond abstract length.

## Open science / data

- Springer research-data policy and a Data Availability statement.
- EMSE open-science board: strongly encourage public artifacts (Zenodo/Figshare); badges after minor/accept; optional and does not change scientific review. **This task does not mint a DOI.**
